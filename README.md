# 👔 Somaiya Men's Wear - Inventory Management System

Final Year BCA Project by **Radhika Shinde**

Live Demo: https://somaiya-men-s-wear-inventory.ai.studio

### 📸 About Shop
Somaiya Men's Wear, Mumbai - Men's Clothing Store. This system manages the real stock of the shop.

### ✨ Features
- 📦 **6617 Total Stock Management** - Real inventory count
- 📷 **Barcode Scanner** - Scan products to add/sell stock
- 🔥 **Firebase Realtime Database** - Live stock update
- 📱 **Mobile Friendly** - Works on shop mobile
- 📊 **Low Stock Alert** - Automatic alert when stock < 10
- 🧾 **Bill Generation**

### 🛠️ Tech Stack
- React + TypeScript
- Firebase
- AI Studio

### 🚀 How to Run
1. Clone this repo
2. `npm install`
3. `npm run dev`
